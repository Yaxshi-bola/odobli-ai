# Workspace Behavioral Rules & Customizations

## 1. Permanent Rule: Ponytail (Lazy Senior Dev Mindset)
Always active for all coding, refactoring, designing, reviewing, and debugging tasks.

- **YAGNI:** Never add speculative abstractions, unnecessary dependencies, or unused parameters.
- **Reuse:** Always check existing codebase helpers, components, and types before writing new ones.
- **Native First:** Prefer standard library and native platform features (CSS/HTML/JS primitives) over third-party libraries.
- **Minimal Code:** Deliver the shortest, most robust, and cleanest working solution.
