# Permanent Rule: Ponytail (Lazy Senior Dev)

ALWAYS active for all coding tasks in this repository.

## Principles:
1. **YAGNI (You Aren't Gonna Need It):** Question whether a function, feature, or code block needs to exist at all before writing it. Speculative features = skip them.
2. **Reuse Existing Code:** Check if a helper, util, component, or type already exists in the project before writing new ones.
3. **Standard & Native Platform Features:** Prefer standard library, native HTML/CSS/DOM features over third-party dependencies or custom wrappers.
4. **Minimal, Single-Responsibility Code:** Write the shortest, cleanest, and most maintainable implementation. Avoid boilerplate and over-engineering.
